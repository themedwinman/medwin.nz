01 — About

What I actually build.

Firstly, you might actually be the first person to read this — so congrats! Besides that sad fact, I spend a lot of my time integrating AI into my homelab through agentic development: building MCP servers that let AI act as a coworker rather than a chatbot.

Most of it runs on a Hetzner VPS in Germany and a Proxmox hypervisor at home, hosting a self-hosted media server, an open-source Bitwarden-compatible vault, and a growing set of AI/MCP services I’ve built myself.

Security is central to how I build and ship all of this. Almanac, my self-hosted long-term memory server, is a good example: it’s exposed over MCP so any authorised AI model can access a knowledge base of me, my projects, and my preferences — the key word being authorised. Because MCP has to run over the public internet, I secured it with passkey authentication, with enrolment locked behind a panel reachable only over my Tailscale mesh VPN, open for a ten-minute window at a time.

Off the résumé.

I’m Oli, a cybersecurity and networks student at AUT in Auckland. I run a Raspberry Pi homelab where I manage DNS filtering with Pi-hole, VPN access with Tailscale, and self-hosted services including a Jellyfin media server, an arr stack, and Vaultwarden — all behind proper access control on a private network.
